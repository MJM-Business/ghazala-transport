# Report fonts

Noto Sans, Noto Sans Arabic and Noto Sans Devanagari are distributed under
the SIL Open Font License in LICENSE.txt. Original files come from:
https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf

GhazalaReportHindi-Regular.ttf is a renamed combination of Noto Sans
Devanagari Regular and Noto Sans Regular. It supplies Hindi and Latin glyphs
in one shaping font for mixed labels such as COD and ETA.
